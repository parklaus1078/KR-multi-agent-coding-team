# 요구사항 파일 예시

> 이 파일은 Project Planner Agent에 입력할 요구사항 파일의 예시입니다.
>
> 사용법: `bash scripts/run-agent.sh project-planner --req requirements-example.md`

---

## 프로젝트 개요

웹 기반 가계부 애플리케이션

**목적**: 개인 및 가정의 수입/지출을 효과적으로 관리하고 시각화

---

## 주요 기능

### 1. 사용자 관리
- 회원가입 / 로그인
- 프로필 관리
- 비밀번호 재설정

### 2. 수입/지출 관리
- 거래 내역 입력 (날짜, 금액, 카테고리, 메모)
- 거래 내역 수정/삭제
- 거래 내역 조회 (필터링, 정렬)

### 3. 카테고리 관리
- 사용자 정의 카테고리 생성
- 기본 카테고리 제공 (식비, 교통비, 주거비 등)
- 카테고리별 예산 설정

### 4. 통계 및 분석
- 월별 수입/지출 요약
- 카테고리별 지출 분석
- 차트 시각화 (파이 차트, 바 차트)

### 5. 추가 기능
- 정기 지출 자동 입력
- CSV 데이터 내보내기
- 다크모드 지원
- 모바일 반응형

---

## 기술 스택

### Backend
- **프레임워크**: FastAPI
- **데이터베이스**: PostgreSQL
- **ORM**: SQLAlchemy
- **인증**: JWT

### Frontend
- **프레임워크**: React
- **상태 관리**: React Context API
- **스타일링**: Tailwind CSS
- **차트**: Chart.js

### 배포
- **Backend**: Docker + Heroku
- **Frontend**: Vercel
- **데이터베이스**: Heroku Postgres

---

## 비기능 요구사항

### 성능
- 거래 내역 조회 속도: 1초 이내
- 동시 사용자: 최소 100명

### 보안
- 비밀번호 암호화 (bcrypt)
- HTTPS 필수
- CSRF 보호

### 접근성
- WCAG 2.1 AA 준수
- 키보드 네비게이션 지원

---

## 우선순위

1. **P0 (필수)**: 사용자 관리, 수입/지출 관리, 카테고리 관리
2. **P1 (중요)**: 통계 및 분석, 차트 시각화
3. **P2 (선택)**: 정기 지출 자동 입력, CSV 내보내기

---

## 제외 사항

- 다중 사용자 공유 (1인 사용만 지원)
- 모바일 네이티브 앱 (웹만 지원)
- 다국어 지원 (한국어만 지원)
- 은행 API 연동 (수동 입력만 지원)
